# Real-Time Chat Application

A live chat app with real-time messaging, built solo using Node.js, Express, and Socket.io.

**Live demo:** https://real-time-chat-application-5yt0.onrender.com

**Tech stack:** Node.js, Express, Socket.io, HBS

**Features:**
- Real-time bidirectional messaging
- Live online user count
- Join with a username, no signup needed
