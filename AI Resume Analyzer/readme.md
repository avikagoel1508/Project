# AI Resume Analyzer

An AI-powered web application that analyzes resumes and provides personalized feedback on strengths, weaknesses, missing skills,
and an overall resume score.

## 🚀 Live Demo
https://ai-resume-analyzer-x6n8.onrender.com

## ✨ Features:
- User authentication and signup/login
- Google authentication
- Resume upload
- AI-powered resume analysis
- Overall resume score
- Identification of strengths and weaknesses
- Missing skills analysis
- User profile and session management

## 🛠️ Tech Stack:
- Node.js
- Express.js
- MongoDB
- Mongoose
- Passport.js
- Handlebars
- JavaScript
- Gemini API
- Multer
